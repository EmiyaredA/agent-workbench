## Go

- 向下传递 context、超时与取消；goroutine 有退出路径，不持锁执行阻塞 I/O。外部调用边界按现有设施处理 panic，handler 的框架兜底不重复实现。
- 错误保留原因链，先判断错误再判断空结果；参考模型 FindOne／FindByXxx 无记录返回 `(nil, nil)`，不把它当数据库故障。
- 缩写通常全大写；参考生成模型的 Id／UserId 依既有生成约定，JSON 与列名 snake_case。结构体、多字段字面量按行展开，空结构体除外。
- 参考注释英文在前、中文括注，解释原因；API 与 JSON 边界字段保留必要含义说明。持久化枚举集中定义、值留空档、不用 iota，稳定性由测试守住。
- 采用 sonic 的项目新 JSON 使用兼容标准配置，第三方内部实现不替换；升级 Go 先核对兼容性，必要时回退标准库，不锁死旧工具链。
- 消息正文放独立模板，已采用 go:embed 的项目在初始化时解析并匹配数据结构，不在业务代码内逐段拼短信、邮件或通知。
