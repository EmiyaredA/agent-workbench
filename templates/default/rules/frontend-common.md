## 通用界面与契约

- 页面沿用统一 API 客户端，不逐页直接拼请求；DTO 逐字段对照契约，返回关联实体名称与关键属性，不用裸 ID 再逐条补查。
- 角色、状态和徽标文字／色调集中定义，未知枚举拒绝侧处理；路由守卫只改善体验，授权以后端为准。统一某种展示时检查同一实体在各页与弹窗的写法。
- 错误按稳定错误码及契约文案显示，不按 message 文本做业务判断。参考协议只有会话失效的 401 触发登出（登录接口自身失败除外），403 提示权限不足；目标项目已有不同会话协议时明确适配，不擅改鉴权。
- 时间沿用接口单位、统一时区和格式化入口；参考 API 返回 Unix 秒，业务日／显示使用北京时间。金额沿用整数最小单位和统一解析／格式化工具，不使用 `Number(x) * 100`。
- 显示含义、关系、单位与口径；一列表达一个概念，不混放状态、截止时间和原因，比例值除外。不影响正确性的输入允许选填。
- 富文本和动态 HTML 先经统一清洗，危险 URL 和事件属性不可执行；凭据沿用项目现有安全存储，不因导入模板改成 localStorage。
- 沿用现有组件与弹窗体系，缺组件做共用实现，不再引入一套替代 UI 库；不使用原生 alert／confirm 作为产品流程。
- 颜色和主题使用集中 token，核对明暗两套配色；参考模板字号至少 14px，已有项目不同密度先审核差异，不套用框架专有类名。
- 多语言词条同结构，显示时才翻译，句子使用完整插槽，不拼碎片；英文按自然表达。中文、英文桌面和手机检查长词、窄卡片、表格与图例溢出。
- 前端修改运行类型检查（含测试文件）、lint、相关测试与构建；不能用测试执行通过替代类型正确。
